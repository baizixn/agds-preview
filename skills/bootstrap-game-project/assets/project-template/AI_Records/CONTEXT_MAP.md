# Context Map

Read repository `AGENTS.md` first. Then read `PROJECT_STATE.md` and only the domain route needed for the task.

| Domain | Canonical context |
| --- | --- |
| Studio workflow, approval, memory, or version control | `AI_Records/OPERATING_AGREEMENT.md` |
| Project direction | Project bible, roadmap, approved decisions |
| Game design | GDD and relevant system document |
| Engineering | technical rules, relevant implementation, current evidence |
| Art | art direction, style guide, asset list |
| Audio | audio direction and cue plan |
| QA | QA plan, relevant test case and raw evidence |
| Research | research brief, sources and dated findings |
